# Habit Tracker 🎯

A modern web application built with React and TypeScript to help users track, build, and maintain healthy habits.

## 🌟 Features

- **Habit Management**: Create, track, and manage multiple habits
- **Progress Tracking**: Visualize your habit completion streaks and progress
- **Analytics Dashboard**: View charts and statistics about your habit patterns
- **Real-time Updates**: Seamless synchronization between frontend and backend
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Beautiful UI**: Built with Material-UI and Tailwind CSS

## 🛠️ Tech Stack

### Frontend
- **React 19** - Modern UI library
- **TypeScript** - Type-safe JavaScript
- **Vite** - Lightning-fast build tool
- **Redux Toolkit** - State management
- **Material-UI (MUI)** - Component library
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animations
- **ApexCharts** - Data visualization

### Backend
- Separate backend service (see [habit-tracker-backend](link-to-backend-repo))
